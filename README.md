# SCT_ML_1

# HOUSE PRICE PREDICTION USING LINEAR REGRESSION

## Project Overview
This project predicts house prices using Machine Learning with Linear Regression.

The model was trained using housing property features such as:
- Area
- Bedrooms
- Bathrooms
- Stories

The project includes:
- Data preprocessing
- Exploratory Data Analysis
- Model training
- Evaluation metrics
- Visualization

---

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook
